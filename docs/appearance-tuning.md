# 玻璃为什么显得薄？如何让细节与体积感更明显

同一套折射算法，放在不同页面里，可能呈现出很不一样的厚度感。这里把独立材质样例与完整界面的差异写清楚，也给出调整顺序。样例保持原样，以下内容是复用思路时的调节建议。

## 样例验证了什么

截至 2026-11-05 核对，教堂背景样例与原界面使用的 `home-liquid-v5.js` 内容完全相同。样例中的折射、烟灰吸光和边缘光学来自生产引擎，但外层 CSS、背景处理及组件尺寸经过简化。它能展示两种材质预设，并不等于完整界面的最终观感。

透明与烟灰预设共用光学算法；烟灰预设还将折射强度乘以 `1.06`、高光强度乘以 `0.92`，并使用不同的色调与边缘参数。因此，图中两块玻璃是“两个完整预设”的对照，不能把差异全部归因于透射率。

| 项目 | 独立材质样例 | 原界面聊天气泡 |
| --- | --- | --- |
| 光学引擎 | 生产 v5 JavaScript | 同一份代码 |
| 背景蒙层 | 深色 `rgba(7,9,12,.08)` | 日间白色 `.46`；夜间黑色 `.46` |
| 外部投影 | 统一 `0 8px 24px #0003` | 按主题与材质分别设置；透明气泡使用两层投影 |
| 高度与圆角 | 固定高 `132px`、圆角 `28px` | 按内容决定高度，圆角约 `20px` |
| 聊天材质基础控制值 | `blur: 0`、`tint: 0` | 同样为 `0`；独立的烟灰衰减与边缘着色仍然存在 |

这些数值记录当前实现，不是所有项目都应照抄的标准。背景蒙层作用于整个场景，并不是玻璃自己的不透明度。

## 先分清要增强哪一种效果

| 想看到的效果 | 优先调整 | 调整过头时的表现 |
| --- | --- | --- |
| 背景穿过玻璃后发生弯曲 | 背景特征尺度、折射位移 `refract` | 字形和纹理被拉扯，像液体涂抹 |
| 边缘有厚度 | 内侧暗边、局部高光、圆角与边缘宽度比例 | 整圈黑框或白色描边 |
| 玻璃浮在页面上 | 外部投影的近层与远层 | 像厚重的按钮或浮雕 |
| 柔和的磨砂感 | 背景采样的模糊半径 | 透射细节消失，变成灰白色板 |

透明感与体积感可以同时存在。基础 `blur: 0` 也能有厚度；更强的折射不一定会带来更强的厚度。

## 1. 给边缘留出能被看见的背景

密集树枝、石墙和窗框很适合验证“有没有折射”，但容易掩盖细小的亮边与暗边。可以选有大块明暗、少量清晰轮廓的背景，或适量降低场景对比，让玻璃边缘与投影有可见的落点。纯色背景则缺少可供观察的纹理位移，不适合单独验证折射。

如果增加场景蒙层，应同时更新可见背景和供 Shader 采样的背景纹理。只把页面背景压暗、却仍让玻璃采样未经处理的原图，会让玻璃内部与外部亮度对不上。

下面沿用当前实现的变量名，两个位置读取同一个颜色值：

```css
:root { --theme-page-overlay: rgba(255, 255, 255, .46); }
html[data-resolved-theme="dark"] {
  --theme-page-overlay: rgba(0, 0, 0, .46);
}
.wallpaper::after {
  content: "";
  position: absolute;
  inset: 0;
  background: var(--theme-page-overlay);
}
```

```js
// 先按组件在视口中的位置裁出同一张壁纸，再应用同一场景蒙层。
// 调用方已经处理画布尺寸、DPR 和裁切坐标。
ctx.drawImage(image, dx, dy, dw, dh);
const overlay = getComputedStyle(document.documentElement)
  .getPropertyValue('--theme-page-overlay').trim();
if (overlay) {
  ctx.fillStyle = overlay;
  ctx.fillRect(0, 0, width, height);
}
```

`.46` 是原界面当前取值。调试时从较轻的蒙层逐步增加，并保留可见纹理；样例当前的 `.08` 无需为此修改。

## 2. 用两层投影区分贴边感与悬浮感

近层投影帮助识别轮廓与页面的分离，远层投影提供柔和的悬浮感。两层都可以很轻，深色背景与浅色背景需要分别检查。

下面数值取自原界面日间透明气泡，选择器改为通用名称；应放在项目最终控制投影的规则中，避免被既有 `!important` 覆盖：

```css
.glass-card {
  box-shadow:
    0 7px 18px rgba(20, 26, 38, .105),
    0 2px 5px rgba(20, 26, 38, .035);
}
```

想增强悬浮感，可以一次小幅调整其中一层的透明度或偏移，观察轮廓是否更清楚。阴影更黑并不保证更立体：样例的单层阴影透明度为 `.20`，仍可能被复杂背景淹没。投影改变的是玻璃与页面的空间关系，内侧厚度还需要边缘光学配合。

## 3. 配合内侧暗边与局部高光

边缘的明暗变化应有位置与方向，而不是给四周加等宽、等亮的描边。当前 Shader 会根据实际采样颜色的亮度，调整烟灰暗边宽度与吸光强度：亮背景中暗边更窄、更轻，暗背景中保留更多厚度。这不是单纯由日间／夜间主题切换决定的。

已有实现中可分别微调 `smokeWidth`、`smokeEdgeLoss`、`smokeClearGain`，观察内侧暗边与清透折射带的配合；透明材质则观察 `edge`、`shine` 及方向性高光。提高这些值会同时影响材质明暗，宜小步单独调整。当前聊天材质在亮背景中还会把局部边缘高光转成暗色点缀，因此 `shine` 不是统一的“变厚”开关。

## 4. 按组件真实尺寸判断边缘比例

当前实现混合了两种尺度：镜面变化使用中心到圆角边界的归一化坐标，部分暗边与细高光宽度使用 CSS 像素。同样几像素的边缘，在矮气泡上占比更大，在大卡片上显得更细。

复用时至少检查单行气泡、多行气泡与大卡片，分别观察圆角、内侧暗边和投影的比例。调大卡片可以考虑适量增加边缘宽度或投影范围；小气泡则可能需要减轻，否则容易显得鼓胀。不要仅通过放大截图来判断参数效果。

## 建议的调节顺序

1. 固定同一张背景、裁切位置、组件尺寸与动画时间，先比较实际差异。
2. 调整场景对比或蒙层，保证采样与可见背景一致。
3. 调整外部投影，确认玻璃与页面之间的距离感。
4. 按尺寸微调内侧暗边和局部高光，确认边缘厚度。
5. 最后再考虑折射位移与模糊半径，避免用背景扭曲或磨砂掩盖轮廓问题。

每次只改一项，并同时检查亮区与暗区。这里对截图观感的解释属于基于代码和图像的判断，并未通过控制变量实验给各因素分配贡献比例。
